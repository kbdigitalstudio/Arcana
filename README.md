# ARCANA

> Misterio sin cliché.

Tarot · Astrología · Lecturas — experiencia web premium construida con Next.js, TypeScript, Tailwind CSS, Motion y Lucide.

Estudio: KB Digital Studio.

## Desarrollo

``nmpm run dev
mpm run build
mpm run lint
``n
## Configuración

- WhatsApp: editar WHATSAPP_NUMBER en src/lib/whatsapp.ts.
- Precios de lecturas: src/data/readings.ts (placeholders editables).
- Cartas: src/data/cards.ts + arte en public/cards/.
- Retrato: public/images/ (ver public/README.md).
